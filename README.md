# 🏀 全場灌籃 Full Court Slam

一個純前端、零依賴的 **3 對 3 全場籃球遊戲**（HTML5 Canvas）。可以灌籃、投三分、打全場攻守轉換。

**線上遊玩：<https://timemap26-sudo.github.io/basketball/>**

或直接用瀏覽器打開 `index.html` 就能玩（電腦或手機皆可）。每次推送到 `main` 都會透過 GitHub Actions 自動部署到 GitHub Pages。

## 玩法

鍵盤配置：**右手方向鍵移動，左手 `A` `S` `W` `D` `X` + `空白鍵` 做所有動作**。

| 動作 | 鍵盤 | 手機 |
| --- | --- | --- |
| 移動 | 方向鍵（右手） | 左側搖桿 |
| 衝刺 | `A` / `Shift` | 搖桿推到底，或點衝刺鍵開關 |
| 跳 / 搶籃板 / 蓋火鍋 / 跳球 | `W` | 跳躍鍵 |
| 投籃 | `D`：**按住**起跳，在量表綠區**放開** | 投籃鍵 |
| 灌籃 | 靠近籃框時按 `D`（衝刺時距離更遠） | 投籃鍵 |
| 花式灌籃 | 靠近籃框時按 `S`（風車、360 度、360 度風車、胯下換手、背後反扣、空中拉桿、540 度、搖籃灌籃） | 花式鍵 |
| 超遠距灌籃 | 按住 `A` 同時按 `S`：三分線內任何地方都能起飛灌籃 | 開衝刺 + 花式鍵 |
| 抄截 | 防守時靠近持球者按 `S` | 投籃鍵 |
| 傳球 | `X`（可配合方向鍵選擇隊友） | 傳球鍵 |
| 換人 | 沒持球時按 `X`（切換到離球最近的球員） | 傳球鍵 |
| 晃人 | 持球時按 `空白鍵`：往方向鍵的上/下（沒按就左右交替）急切換手，前方的防守者可能被晃倒 | 晃人鍵 |
| 暫停 / 靜音 | `P` / `M` | II |

每節最後 3 秒會有「嗶、嗶、嗶」倒數聲，時間到響終場蜂鳴器。

**發球**：得分後由對手從底線外發球，出界、違例後從球出界的邊線或底線外發球。發球的人不能移動、不能投籃，只能按 `X`（手機按傳球鍵）把球傳進場，超過 5 秒沒傳就是 5 秒違例；球傳進場後才開始計算 24 秒。

主選單可以調整 **三分命中率**：預設（看出手時機）、40%、60%、80%、100%。設成 100% 時，你這隊在任何位置投三分都會進，而且不會被蓋。

## 連線對戰（和朋友 1 對 1）

1. 主選單按 **建立房間**，會得到一組 5 碼房間代碼和一個邀請連結。
2. 把連結傳給朋友（或讓對方按 **加入房間** 輸入代碼）。
3. 連上後自動跳球開始：建立房間的人控制 **烈焰隊（紅）**，加入的人控制 **浪潮隊（藍）**，隊友由電腦控制。

- 使用 WebRTC 點對點連線（[PeerJS](https://peerjs.com/)，已放在 `vendor/`），不需要自己架伺服器；配對時會用到 PeerJS 免費的公開配對伺服器。
- 由建立房間的一方執行比賽運算，加入方傳送按鍵、接收畫面；投籃時機依加入方自己按住的時間計算，不受網路延遲影響。
- **聊天室**：連線時畫面下方有聊天框（和網球遊戲相同），電腦按 Enter 或點一下就能打字，Enter 送出、Esc 收起；也有「👍 好球！」「GG」等快捷語，訊息會以對話泡泡顯示在說話者的球員頭上。
- **語音聊天**：連線時點聊天框旁的 🎤 開啟麥克風，就能直接和對手講話（再點一下關閉）；🔊 可以把對手靜音。說話時球員頭上會出現 🎤 圖示。第一次使用時瀏覽器會詢問麥克風權限；建議戴耳機以免回音。
- 對手斷線時，比賽會由電腦接手繼續；比賽結束後房主按 Enter 可以再來一場，Esc 離開。
- 少數嚴格的公司或學校網路可能擋住點對點連線，換成手機熱點通常就能連上。

## 特色

- **全場攻守**：進球後對方從底線發球，球員全場跑動、快攻、退防；人盯人防守。
- **灌籃**：暴力灌籃、風車、戰斧、360 度，會被防守者封阻（REJECTED!）。
- **投籃量表**：出手時機決定命中率；三分線外出手得 3 分（含底角三分），防守干擾會降低命中率。
- **真實的球物理**：籃框、籃板反彈、滾框進球、籃板球。
- 24 秒進攻時限、出界、抄截、攔截傳球、蓋火鍋、壓哨球、延長賽。
- 三種難度、每節 1 / 2 / 3 / 5 分鐘，賽後數據統計。
- 主選單背景是電腦對電腦的示範比賽。
